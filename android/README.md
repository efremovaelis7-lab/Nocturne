# NOCTURNE для Android

Тот же интерфейс (`app/`) и тот же сервер библиотеки (`desktop/core`), что на Mac и Windows, внутри приложения Android:

- окно — системный WebView на весь экран;
- сервер библиотеки собирается из `desktop/cmd/nocturne-server` под Android и лежит в APK как `libnocturne.so`
  (Android разрешает приложениям запускать программы только из папки нативных библиотек);
- сервер слушает только `127.0.0.1` и отвечает лишь на запросы с одноразовым секретом, который приложение
  при каждом запуске передаёт своему WebView. Другие приложения на телефоне библиотеку прочитать не могут.

## Где хранятся данные

Во внутренней памяти приложения (`files/home`): библиотека — `Documents/NOCTURNE`, настройки и `server.log` —
`.config/NOCTURNE`. Файлы, которые страница «скачивает» (архивы, выгрузки книг), сначала попадают в
`Downloads`, а приложение сразу спрашивает, куда их сохранить, и после этого удаляет копию.

При удалении приложения библиотека удаляется вместе с ним.

## Сборка

Автоматически на GitHub: `.github/workflows/android.yml` запускается при изменениях в `android/`, `app/` или `desktop/`.
APK появляется на странице выпуска `android-test`, журнал сборки — в ветке `android-builds`.

Вручную (нужны Go 1.23+, JDK 17 и Android SDK, например из Android Studio):

```sh
bash android/build-android.sh      # сервер под Android + копия интерфейса
cd android && ./gradlew assembleRelease
```

## Ключ подписи

Все версии приложения должны быть подписаны одним и тем же ключом, иначе новая версия не установится поверх
старой. Ключ хранится в секретах репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `NOCTURNE_KEYSTORE_B64` | файл ключа (`.jks`) в base64 |
| `NOCTURNE_KEYSTORE_PASSWORD` | пароль файла |
| `NOCTURNE_KEY_ALIAS` | имя ключа |
| `NOCTURNE_KEY_PASSWORD` | пароль ключа |

Без секретов APK подписывается временным ключом — для проверки этого достаточно.
Файл ключа нельзя класть в репозиторий.
